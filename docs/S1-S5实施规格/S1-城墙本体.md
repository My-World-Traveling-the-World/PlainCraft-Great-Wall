```java
package local.plaincraft.greatwall.geometry;
public final class FixedMath {
    public static final int Q8 = 256, Q16 = 65536;
    private FixedMath();
    public static long mulDiv(long a, long b, long positiveDivisor);
    public static long roundDiv(long numerator, long positiveDivisor);
    public static long isqrt(long nonNegative);
    public static long hypotQ8(long dxQ8, long dzQ8);
    public static int smoothQ16(int tQ16);
    public static long lerp(long a, long b, int tQ16);
    public static int floorBlock(long q8);
    public static int chunk(int block);
    public static long distanceSquared(int ax, int az, int bx, int bz);
}
```

```text
mulDiv：divisor>0；BigInteger(a)*BigInteger(b)，除以divisor向负无穷取整；longValueExact。
roundDiv：q=floorDiv(n,d),r=floorMod(n,d)；r>d-r则q+1，否则q；平局取较小整数。
isqrt：n<0拒绝；二分lo=0,hi=min(n,3037000499)+1；mid<=n/mid则lo=mid，否则hi=mid；mid=0特判；返回lo。
hypotQ8：只接受abs(dx),abs(dz)<=2^30；sum=multiplyExact平方后addExact；取isqrt，比较sum-r²与(r+1)²-sum，平局取r。
smoothQ16：t∈[0,65536]；返回floor(t*t*(3*65536-2*t)/65536²)，long中间值。
lerp：a+mulDiv(b-a,t,65536)，t合法，add/sub exact。
floorBlock：toIntExact(floorDiv(q8,256))。
chunk：floorDiv(block,16)。distanceSquared：先转long再减，平方/和exact。
```
