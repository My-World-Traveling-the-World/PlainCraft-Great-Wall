### 构造、比较和 accessor 行为

每个 record 生成其字段顺序一致的 public canonical constructor；以下检查直接写进对应 compact constructor。

```text
所有 constructor：
  Objects.requireNonNull 每个引用字段；不用 null 表示 optional。
  List→List.copyOf；Map→Map.copyOf；Set→Set.copyOf；元素不得 null；嵌套集合再逐层复制。
  所有 hash 必须 64 位小写 hex；资源 key 必须 namespace:path 格式。
  Bounds 要 min<max；DimensionBounds maxY>minY、horizontalLimit>0。
  Axis/Frame 方向向量平方与 2^60 的相对误差≤2^-27；超出拒绝。
  ArcInterval to>from；允许水文halo使用负的段内S，全球S区间的调用者另检查from>=0。
  SegmentKey index>=0；SiteId ordinal>=0；BeaconId ordinal>=1。
  GateId namespace 只允许 planned/fort/negotiated；ordinal>=0。
  points 至少2且数量==localSQ8；localSQ8[0]=0，之后严格递增。
  station.globalSQ8 严格递增；站位在维度可写高度内。
  logicalColumns 0..150000；degradation 0..3；gateRevision>=0。
  RouteShape.searchColumns<=120000，boundaryColumns<=2；邻域同recipe且编号恰为i-1/i/i+1，段0无previous。
  BlockSpec properties 键值为 ASCII 有界字符串；id 不存在由资源 binder 拒绝。
  Coverage tileBases 每项 floorMod(base,128)==0，升序去重。
  ComponentInput材料ribbon必须覆盖组件S两端各8格；S1使用固定族fixture，不为null。
  WorldRecipe.dimension 固定 minecraft:overworld；非主世界服务返回显式 NO_WALL，不创建第二条墙。
accessor：返回字段；集合已深复制不可变，无 getter 返回可写数组。
```

存储及 canonical sort：ChunkKey 按 dimension UTF-8、x、z；SiteId 按 wallId、kind 名称、ordinal；Point3i 按 y,z,x；SegmentKey 按 recipe,dimension,index。禁止依赖 Map.copyOf 的迭代顺序，编码前显式排序。

flags：`1=PLATFORM`、`2=BOUNDARY`、`4=RAMP_ENTRY`、`8=WATER`、`16=BREAK_EDGE`；未知位拒绝。默认 GenerationConfig 固定 `(1,1,2048,4,150000,384,192,4,67108864,67108864,33554432)`。配置变化须新世界。每个 instance 仅用于历史隔离；wallId=`SHA256(recipe semantic inputs excluding instance)`，不能把 UUID 混进几何随机。

水文坐标：`SegmentGeometry.water[].crossing`以该段首点S=0，完整跨岸区间允许from<0或to>段长；同一跨段河流的两份证据仅参考原点不同。送入`ComponentInput.waters`之前由`RealizationPlanner`加该段`prefix.lengthBeforeQ8`转全球S，以两岸世界坐标、全局entry/exit、水位作为去重键。不得裁成两个各自计宽的半条河。terminal仅由包含真实entry的半开段发布；从第0段起就湿且无法取得入岸时明确ROOT_NOT_FOUND。负的局部S不进入全局日程或永久ID。

## local.plaincraft.greatwall.model.PlanLease

文件：`D:\云游四海-Mod源码\plaincraft-great-wall\src\main\java\local\plaincraft\greatwall\model\PlanLease.java`。并发基础/JUnit，R1/R2/P1/P2。

```java
package local.plaincraft.greatwall.model;
public final class PlanLease<T> implements AutoCloseable {
    private final UUID id;
    private final CompletableFuture<T> view;
    private final Runnable release;
    private final ConcurrentHashMap<String,Boolean> state;
    public PlanLease(UUID id, CompletionStage<T> shared, Runnable release);
    public UUID id();
    public CompletableFuture<T> future();
    public void close();
}
```

```text
ctor：shared.whenComplete 转发到新建 view，绝不把 view.cancel 传向 shared。
id/future：返回 id / view；future 是该申请者独占的可取消 promise。
close：state.putIfAbsent("closed",true) 成功才取消 view 并 release.run；repeat 无操作。
完成不会自动 release：消费者用完 plan 才 close；超时/错误由消费者 finally close。
```

## 坐标、实体几何与窗口（不可自行换约定）

- 世界方块坐标 int；世界 Q8 与 S 为 long；浮点只用于锁定 CPU 密度函数与 `StrictMath` 方向表，结果量化后参与规划。
- local X 沿墙正切，local Z 沿左法向，无关内外；局部方块取中心 `(x+0.5,z+0.5)` 投影。偶数10宽区间 `[-5,5)`，8宽 `[-4,4)`；11宽敌楼镜像前 `[-5,6)`。Fort `[-24,24)`。
- 所有 `ComponentTemplate.localBounds` 的Y是相对W的偏移，`Rasterizer.worldBounds`只加一次W；形状规则中写`g/W`的Y是绝对高度，判定时用`world.y`或先减W转换，严禁再加一次。`Point3i local`的Y恒为`world.y-W`。
- `groundTopY=h` 永远是支撑方块**上表面脚面整数**，支撑块是 `y=h-1`；W是步道脚面，地板 `W-1`，g=`W-20`，名义墙体 y=`g..W-1`。一切 drop 用 `max(0,g-h)`。
- 候选脚面严格 h∈[W-32,W+6]。验证最低候选 h=W-32 必须读取 y=W-33；三层承重厚度又要 y=W-34,W-35。这是算术必需的**承重 guard**，不把搜索窗口改成 `[W-35,...]`。T0 read coverage 因此从 min(W)-35 起，含所有构件写集和上边界哨兵 W+7；上方自然高物体由 FEATURES heightmap/保护摘要证明，不能把页截断当空气。drop=12 合法、13拒绝。
- 自有持久坐标三 int；仅 Minecraft 原生 chunk 调度键允许 ChunkPos.toLong（不含Y）。本模组历史绝不存 BlockPos.asLong。
- horizontalLimit 为原版边界、实际 BlockPos 打包能力和冻结世界边框的最小可用范围再减 1024 guard；超限发 WORLD_LIMIT terminal。后续边框扩大不延长已冻结 recipe，缩小只限制玩家活动不重画墙。

## 冲突、高度和日程的统一决议

物理日程：tower slot `S=300*n,n>=1`，奇数敌楼偶数烽火台；Beacon ordinal=n/2。gate `800*k+jitter[-100,100]`；fort `4000*m+jitter[-500,500]`，fort0在S0，gate0不另造简易门。每个站位半开归属，所有尺度Q8。

相邻候选冲突不采用“先到先得”：对有重叠足印的全部 site 建连通分量，priority FORT>GATE>BEACON/ENEMY_TOWER>RAMP，priority相同按完整 SiteId；每分量至多包含一个 fort（超出报 BUDGET_EXHAUSTED），总长上限256格。胜者地面/平台合同统一。被吸收的 beacon/tower 保留原 ordinal，挂在胜者预留的侧翼 socket 上；socket 不足将低优先级 site 标 SUPPRESSED(CONFLICT)，不更改日程。统计计划间隔与实际有效间隔分别输出。

跨段平台：先有纯边界 W=oracle(anchor).groundTop+20，再处理站位。平台含段边界时使用该边界W；不含时取平台足印9点地面中位数+20；若两个固定边界不等且都被同平台包含，整个site SLOPE。禁止先改W再让相邻段重新迭代。

## 持久协议

### 存储树

世界根目录下 `data/plaincraft_great_wall/`：

```text
manifest/creation.json          首次授权 token，含 instance 和语义配置hash
manifest/world.json             已冻结 recipe，immutable + SHA
cache/<recipe>/<dimension-hash>/volume_<i/256>/segment_<i>_<hash>.bin
cache/<recipe>/prefix/checkpoint_<index>_<hash>.bin
evidence/<recipe>/<dimension-hash>/<cx>_<cz>/coverage.bin
evidence/<recipe>/<dimension-hash>/<cx>_<cz>/<tileBase>.t0
evidence/<recipe>/<dimension-hash>/<cx>_<cz>/build-proof.bin
history/wal_<generation>.bin
history/shards/<kind>/<shard>.bin
history/checkpoint_<generation>.bin
history/HEAD                     immutable代际指针，原子替换
```

cache 可删；其余不可删后重算。SavedData `plaincraft_great_wall` 是提交历史的派生索引，但不得在磁盘异常时自动返回新空实例，必须先 journal 恢复和一致性检查。history/HEAD仅持有固定的by_key/by_sequence两个索引根引用及计数，不把无限增长的全部分片目录装入内存；完整有界页格式见S3 HistoryTypes。

### Canonical 数据编码

大端 `DataOutputStream`；int32长度+UTF-8字符串（最长4096字节）、布尔1字节、整数Java对应有符号宽度、double只有原始指纹使用IEEE位；Optional先bool。record按声明字段顺序；List按其合同顺序；Map按key UTF-8排序；枚举写名称字符串。hash字段本身不参与自身hash。编码上限：geometry 2MiB，plan 4MiB，chunk proof 8MiB，单history record 1MiB，单checkpoint shard 16MiB。

缓存 header：magic PGW1/int32、schema/int32=1、algorithm/int32、seed/long、dimension/string、recipe/32bytes、segment/long、rawLength/int32、compressedLength/int32、CRC32C/long、payloadSHA/32bytes。payload deflate，先检查长度再解压到 `limit+1`。cache错误计数并只重试重算一次；永续错误禁止静默修复。

T0 沿用已签收 S0 编码与类，页索引base按128对齐，页实际Key.minY=max(base,dimension.minY)、maxY=min(base+127,maxYExclusive-1)，S0 Key.maxY为**闭端**。底/顶页可少于128，不向维度外读取。production 路径隔离，不能复用S0金块实验目录。coverage.bin保存CaptureMetadata（含规划Coverage与FEATURES高度/保护摘要），与build-proof同样length/CRC/SHA封装。marker保存recipe、coverageHash、proofHash、complete、revision，不只一个字符串“done”。

### 固定容量与线程

四个进行中 geometry、两个 CPU oracle lane、IO单writer排队≤128；段缓存64MiB/256项、T0 64MiB、compiled32MiB/1024项。S5测量达到上限则背压，不能逐出pinned、不能丢需求当无墙。所有 map/队列元数据也记账；完成future从inflight按identity remove；caller lease数有限4096，超限返回可重试CAPACITY，不无限挂promise。

所有阻塞磁盘方法只在IO owner调用，所有 entity/SavedData/已加载回填仅server主线程；所有异步续调显式指定所属executor。锁内回调不做磁盘、不等future、不触发另一个owner的施工。统计时间不进几何hash。

### 故障语义

原子 move 不可用：生产 manifest/T0/journal checkpoint 创建失败，APPLY前停止；不做非原子覆盖 fallback。缓存可丢临时文件。WAL尾端不足一个完整record可保存坏尾副本后截到最近提交；完整record CRC错即使是最后一条也视损坏，不能猜它没提交。中部损坏隔离、拒绝发任务奖励或新施工。
