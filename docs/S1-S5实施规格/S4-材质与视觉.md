## local.plaincraft.greatwall.decay.PaletteTypes

文件：`D:\云游四海-Mod源码\plaincraft-great-wall\src\main\java\local\plaincraft\greatwall\decay\PaletteTypes.java`。纯模型/JUnit，R2/R3。

```java
package local.plaincraft.greatwall.decay;
public final class PaletteTypes {
    private PaletteTypes();
    public enum Variant { STONE, DEEPSLATE, SANDSTONE, RED_SANDSTONE }
    public record BiomeStation(long globalSQ8, String biomeKey, Variant variant) {}
    public record Weight(Variant variant, int weightQ16) {}
    public record Mix(List<Weight> weights, String hash) {}
    public record WeightedState(BlockSpec block, int weight) {}
    public record Table(Variant variant, DecayState decay, Part part, List<WeightedState> entries) {}
    public record Catalog(Map<Variant,Map<DecayState,Map<Part,Table>>> tables, String hash) {}
    public record Snapshot(Set<String> sandstoneBiomes, Set<String> deepslateBiomes,
        Set<String> redSandstoneBiomes, Catalog catalog, String hash) {}
    public record Validation(List<String> errors, String blocksHash, String tagsHash) {}
}
```

构造：深复制嵌套maps/sets/lists；BiomeStation.S>=0且同input列表严格递增；Weight0..65536；Mix仅非零项且sum65536，顺序Variant声明顺序。Table.entries正整数总100，不用alias算法或浮点；每个Variant×Decay×Part必须存在（AIR/特殊part也有固定100行）。SHA由内容生成，Catalog不能接受外部给的假hash。Validation.errors为空才允许ready。

## local.plaincraft.greatwall.decay.PaletteBlend

文件：`D:\云游四海-Mod源码\plaincraft-great-wall\src\main\java\local\plaincraft\greatwall\decay\PaletteBlend.java`。纯函数/JUnit，R2/R3。

```java
package local.plaincraft.greatwall.decay;
public final class PaletteBlend {
    private PaletteBlend();
    public static PaletteTypes.Mix at(long globalSQ8, List<PaletteTypes.BiomeStation> ribbon);
    public static PaletteTypes.Variant choose(PaletteTypes.Mix mix, long voxelHash);
}
```

```text
at：把相邻采样站中点作为类别边界，b=floorDiv(Si+Si+1,2)；同类不生成边界。
  形成有限的piecewise-constant类别区间，端点0只向后延拓首类；海洋terminal后只延拓末类供收头。
  积分窗口[S-4*256,S+4*256)，总长2048Q8：逐区间intersection长度加到4类；
    三个以上边界落同窗口也累计全部，不挑“第一个边界”。缺halo则输入错误。
  每类floor(length*65536/2048)，余数按(余数降序,Variant序)分配至和65536；删除0项。
  hash canonical权重。单边界b-4纯左、b正中各32768、b+4纯右，严格8格带。
choose：q=bounded(hash,65536)，顺序累计权重，第一个q<累计值即选中；边界用半开，不四舍五入漂移。
```

素材选择用世界三int+Part分域hash，不混ownerChunk、当前线程、模板遍历序或实时FPS。同坐标同Part的皮肤在重复编译和邻chunk上完全一致。材料过渡不改变VoxelIntent的kind/required/solid几何。
