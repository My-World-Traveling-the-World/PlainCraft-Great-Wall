## 核心规则

- **协商门状态**：`REUSED / FROZEN_PENDING / READY / PROTECTED_GAP / CANCELLED`；候选 cell=`floorDiv(crossingSQ8,128*256)`，中心 `(cell*128+64)*256`，offset `[0,-16,+16,-32,+32,-48,+48]*256`。复用门交点 ±192S；7 候选全失败 → PROTECTED_GAP，不开更宽门。
- **恢复**：RecoveryCoordinator Status `CLEAN/RECOVERED_PARTIAL_TAIL/NEEDS_OPERATOR/INCOMPATIBLE`；永久历史损坏不能 cache rebuild；manifest/evidence 创建失败可见，禁止非原子 fallback。
- **故障矩阵**：18 个 FaultInjector.Point × {exception, halt} × 10 轮；halt → `Runtime.halt(137)`；磁盘满用测试 FileChannel 拒写，不写满真实磁盘。
- **压测**：并发限 {1,2,8,16}；24h 每 60s metrics、每 30min afterGC 快照；切片计时目标 25ms、观测 40ms（**2026-10-05 用户授权：40ms 由硬拒绝改为仅记录**，其它 mod 抢占 CPU 不再让整个生成失败）；堆平台 afterGC 斜率 ≤1MiB/h。

## 构建任务

`production-tests.gradle` 固定名：`runProductionServerSmoke` / `runRealTerrainMatrix` / `runS2RoadTests` / `runS3FtbTests` / `runS4Gallery` / `runS5Faults` / `runS5Stress` / `verifyReleaseArtifacts`。全部复用现有 Loom sourceSet/runs，不手拼 classpath；test/fault/fixture/agents 绝不进 main/client Jar。

正式命令：

```powershell
$env:JAVA_HOME='C:\Program Files\Java\jdk-21'
.\gradlew.bat --offline --dependency-verification=strict clean build
.\gradlew.bat --offline --dependency-verification=strict runGameTest
.\gradlew.bat --offline --dependency-verification=strict verifyReleaseArtifacts
```

## 发布签收

1. mod_version=0.1.0，依赖版本一个不改。
2. artifact=remapJar + sourceJar；zip 无 test/fault/fixture/agents/凭据/机器路径。
3. 同源码同 JDK 连续两次 clean build remapJar SHA 一致。
4. 专用服+客户端验证 core only / FTB / Road / Tectonic / C2ME CPU / fullpack OpenCL。
5. pack.mcmeta 34..48，datapack 48 / resourcepack 34，目录单数。
6. 新世界创建/重进/同 JVM A→B/改 seed/维度/资源指纹/旧 world 拒绝/原子文件拒绝逐项证据。
7. `docs/release/acceptance.json` 全 PASS 才写"全 S5 通过"。

真实 metrics/stress、exception/halt 故障恢复全矩阵、长压/24h 尚未签收（见 `docs/release/preview-status.md`）。
