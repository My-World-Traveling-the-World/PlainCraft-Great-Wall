STRUCTURE_STARTS。若增加专门的异步 structure-start port，必须审核生产阶段
依赖、锁外租约、取消/异常/关闭释放和 81-chunk 上限；不直接复用 bootstrap
的实例或反向等待 recipe。此项尚未改动。

不能用缓存绕过。只延长 timeout 或放行 TRACE_TRUNCATED 不是修复。
