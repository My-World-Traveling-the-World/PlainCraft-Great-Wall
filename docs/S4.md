## 核心规则

- **族分类**：`red` 且 `sandstone` → RED_SANDSTONE；`sandstone` → SANDSTONE；`deepslate` → DEEPSLATE；否则 STONE。重叠优先 sandstone > deepslate > stone。
- **过渡带**：相邻采样站中点 `floorDiv(Si+S(i+1),2)` 为边界；积分窗口 `[S-4*256, S+4*256)` 总长 2048Q8；每类 `floor(length*65536/2048)`，余数按 (余数降序, Variant 序) 分配至和 65536，删 0 项。严格 8 格带：单边界 b-4 纯左、b 正中各 32768、b+4 纯右。
- **皮肤选择**：`family` 与 `skin` 分域 hash（`material-family` vs `material-skin`），不混用同一 bits；同坐标同 Part 皮肤在重复编译与邻 chunk 上完全一致。
- **资源 ID**：`minecraft:hay_block`（非 hay_bale）；`lantern`/`chain`/`campfire`/`chest`/`spawner`/`water`/`air` 固定 100 行。
- **属性冻结**：FLOOR/SLAB=`type=top,waterlogged=false`；STAIR=`half=bottom,shape=straight`；CAMPFIRE=`facing=north,lit=false,signal_fire=true`；HAY=`axis=y`；WATER=`level=0`。
- **图册**：8 模板白名单（WallSection/EnemyTower/BeaconTower/Gate/WaterGate/EndCap/Ramp/Fort）；族 3×态 4×件 8=96 + red 4×8=32；pitch 128；四态 d=0.10/0.425/0.665/0.90。
